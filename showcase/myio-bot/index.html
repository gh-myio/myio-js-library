MYIO Bot — embeddable widget (RFC-0242)

Carrega o core UMD (dist/myio-js-library.umd.js) e o widget sob demanda com MyIOLibrary.loadBotWidget() — o cenário ThingsBoard. O backend é um stub em memória (mock-bot-api.js, SSE delta/done) passado em fetch: nada sai do navegador. Com ?bot=live o widget fala com um GCDR real usando a API key digitada (não é salva).

Configuração

Modo live: a origem desta página precisa estar em ALLOWED_ORIGINS do GCDR, senão o widget mostra “Sem conexão com o GCDR”.

Handle

No chat do stub: “lembre que…” → cartão de memórias · “inativar elevadores” → cartão de ação (D-20) · “erro” → evento SSE error · “json” → resposta JSON (sem SSE) · /think → T1. Arraste o painel pelo cabeçalho; duplo clique no cabeçalho volta ao canto.
