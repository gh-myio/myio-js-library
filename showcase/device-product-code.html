🏭 Device Product Code (RFC-0230)

Serial de fábrica v2 (código 4 bytes) + nome canônico — conversão sem perda, validação, registry de tipos.

🔓 decodeDeviceProductCode(code) / deviceProductCodeToName(value)

Digite um código B1.B2.B3.B4 e veja os campos decodificados e o nome canônico.

import { decodeDeviceProductCode, deviceProductCodeToName } from 'myio-js-library'; const value = decodeDeviceProductCode('17.2.25.15'); // { year: 2027, month: 1, day: 2, seq3: 0, seq: 25, productType: 15 } deviceProductCodeToName(value); // '3F 270102-0025'

🔒 encodeDeviceProductCode(fields) / formatDeviceProductCode(value)

Preencha os campos (data de fabricação, sequência, tipo) e veja o código e o nome resultantes.

🔁 deviceNameToDeviceProductCode(name)

Digite um nome canônico (PREFIX YYMMDD-NNNN) e veja o round-trip de volta pro código.
